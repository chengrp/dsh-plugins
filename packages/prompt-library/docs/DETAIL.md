# 提示词收藏（Prompt Library）

收藏、整理并复用常用提示词的本地插件。

## 功能

- **侧边栏入口**：侧边栏底部（设置按钮上方）的「提示词收藏」按钮；输入框工具行左侧另有紧凑书签按钮，均可打开收藏面板。
- **管理**：新建 / 编辑 / 删除提示词；每条含标题、正文、标签（标签用于归类与筛选）。
- **筛选与搜索**：按标签 chip 筛选；关键词搜索标题、正文、标签；按「常用 / 最近 / 最新」排序，排序选择会记住。标签默认只显示一行（「全部」+ 使用最多的标签），点「展开 N 个标签」可展开全部，再点「收起」折叠。
- **标签管理**：面板底部「标签管理」可重命名标签（合并到已有标签）或从所有提示词中移除某标签，均为两步确认。
- **悬停预览**：鼠标停在提示词卡片上，会在旁边弹出完整内容预览（标题、标签、全文、使用次数、上次使用、创建日期、字数），长文可在预览内滚动，按 Esc 或移开关闭。
- **一键填入**：点击某条提示词的「填入」，把内容插入当前会话输入框的光标处（输入框未聚焦时追加到末尾，不覆盖已有草稿；输入框旁入口始终可用；侧边栏入口作用于当前主会话，无可填入会话时自动降级为复制）。
- **草稿收藏**：输入框工具行的第二个按钮（带 + 的书签），一键把当前输入框草稿存为新提示词，正文自动预填。
- **导入导出**：面板底部「导出」下载全部提示词为 JSON 备份；「导入」选择此前导出的 JSON 文件合并回来（同 id 更新、新 id 新增，导入的统计数据不覆盖本地）。
- **复制**：不填入时也可一键复制到剪贴板。
- **使用统计**：每条记录使用次数与最近使用时间；面板底部显示「共 N 条 · 累计使用 M 次」。

## 数据

- 仅保存在本机：`~/.dsh/storages/prompt_library/`（DSH 本地 JSON 存储后端），不上传、不同步。
- 删除插件不会主动清除已存数据；如需彻底删除，移除上述目录即可。

## 交互细节

- 输入框旁按钮的面板为避免被裁剪，挂载到页面根节点；
- 侧边栏面板悬浮于按钮上方，点击面板外或按 Esc 关闭；
- 编辑表单支持 Ctrl/⌘+Enter 保存、Esc 取消；
- 删除与标签移除均需二次确认（再点一次「确认」）。
